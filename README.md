# SOLMARA — The Poster for a Place That Isn't There

A travel poster for Solmara, a twin-sunset archipelago where the sun sets
twice: two suns sink over a glass-calm bay, a dark cliff-city glows with
lit windows on the headland, and the place's name is set big in the sky.

`main.py` draws the whole poster in pure Python (standard library only — no
network, no fonts, no third-party packages): layered sunset gradients, twin
suns with halos, a glittering sea, headlands, a cliff-city with lit
windows, birds, and a hand-built geometric display typeface for the name.
It writes a 1024×1024 PNG to `/output/entry.png`, deterministically — the
same bytes on every run.

## Run it

```sh
python3 main.py
# writes /output/entry.png (1024x1024 PNG, ~262 KB)
```
